# LehrZeit – Arbeitszeit für Lehrkräfte

Unabhängige PWA ohne Lovable.

## Funktionen
- lokale Speicherung im Browser
- Arbeitszeit mit Datum, Kategorie, Zeit oder Dauer
- Bearbeiten, Duplizieren, Löschen
- Tages-, Wochen-, Monats- und Gesamtsummen
- JSON Backup/Restore
- CSV Export
- eigene Kategorien
- PWA / Home-Bildschirm
- Offline-Cache via Service Worker

## Wichtig
Für die Installation als PWA muss die App über HTTPS ausgeliefert werden.
Geeignet sind z. B. GitHub Pages, Netlify, Cloudflare Pages oder eigener Webspace mit HTTPS.

## iPhone
1. Webseite in Safari öffnen
2. Teilen
3. „Zum Home-Bildschirm“
4. „Hinzufügen“

Die Arbeitszeitdaten liegen lokal im Browser/App-Speicher des Geräts.
